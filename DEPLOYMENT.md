# DoseVia — Web & Mobile Deployment Guide

This project is a **React + Vite** dashboard wrapped with **Capacitor** for Android and iOS. The same UI, routes, APIs, and styling run in the browser and inside native shells with minimal changes.

---

## Folder structure (after setup)

```
DoseVia-standalone/
├── android/              # Android Studio project (generated by Capacitor)
├── ios/                  # Xcode project (generated by Capacitor; build on macOS)
├── public/               # Static assets
├── src/                  # React app (unchanged logic & pages)
│   ├── lib/
│   │   └── capacitor-init.ts   # Native-only bootstrap (no web UI impact)
│   └── ...
├── dist/                 # Web build output (synced into native apps)
├── capacitor.config.json # Capacitor app ID, name, webDir
├── vite.config.ts        # Vite + base: "./" for mobile asset paths
├── package.json
├── .env                  # VITE_GEMINI_API_KEY (required for AI features)
└── DEPLOYMENT.md         # This file
```

## 1. Initial setup (once)

```bash
cd DoseVia-standalone

# Install dependencies
npm install

# Copy environment template and add your Gemini API key
cp .env.example .env
# Edit .env → set VITE_GEMINI_API_KEY=your_key_here

# Build web assets and create/sync native projects (or use one-shot bootstrap)
node scripts/bootstrap-install.mjs

# Manual alternative:
npm run build
npx cap add android    # skip if android/ already exists
npx cap add ios        # skip if ios/ already exists (macOS recommended)
npx cap sync
```

---

## 2. Run — Web version

**Development (hot reload):**

```bash
npm run dev
```

Open http://localhost:5173

**Production preview locally:**

```bash
npm run build
npm run preview
```

Open the URL shown (default http://localhost:4173)

**Deploy static web build:**

```bash
npm run build:web
```

Upload the `dist/` folder to any static host (Vercel, Netlify, Cloudflare Pages, S3 + CloudFront, nginx, etc.).

> **Important:** Set `VITE_GEMINI_API_KEY` in your host’s environment variables **before** `npm run build`, so the key is embedded at build time.

---

## 3. Run — Android app

**Emulator or device (debug):**

```bash
npm run cap:run:android
```

**Open in Android Studio (recommended for release builds):**

```bash
npm run cap:android
```

In Android Studio: **Run** ▶ on a device or emulator.

After any code change:

```bash
npm run cap:sync
# Then rebuild/run from Android Studio
```

---

## 4. Generate APK / AAB (Android release)

1. Open the project:

   ```bash
   npm run cap:android
   ```

2. In Android Studio: **Build → Generate Signed Bundle / APK**
3. Choose **APK** (side-load/testing) or **AAB** (Google Play)
4. Create or select a keystore, pick **release**, finish the wizard
5. Output: `android/app/release/app-release.apk` (or `.aab`)

**Command-line release APK (after signing config in `android/app/build.gradle`):**

```bash
cd android
./gradlew assembleRelease
```

APK path: `android/app/build/outputs/apk/release/`

---

## 5. Run & build — iOS app (macOS only)

**Simulator or device (debug):**

```bash
npm run cap:run:ios
```

**Open in Xcode:**

```bash
npm run cap:ios
```

In Xcode: select a simulator or connected iPhone → **Run** ▶.

First time on a physical device:

1. Xcode → **Signing & Capabilities** → select your Team
2. Trust the developer certificate on the device (Settings → General → VPN & Device Management)

After code changes:

```bash
npm run cap:sync
```

Then rebuild in Xcode.

---

## 6. iOS App Store build

1. `npm run cap:ios`
2. Xcode → set **Bundle Identifier** (matches `appId` in `capacitor.config.json`: `com.DoseVia.dashboard`)
3. **Product → Archive**
4. **Distribute App** → App Store Connect or Ad Hoc / TestFlight

## 7. App icons & splash (optional)

Uses existing `public/favicon.svg` as source:

```bash
npm install -D @capacitor/assets
npx capacitor-assets generate \
  --iconBackgroundColor "#ffffff" \
  --splashBackgroundColor "#0f172a"
npm run cap:sync
```

## 8. Environment variables

| Variable              | Used for                        |
| --------------------- | ------------------------------- |
| `VITE_GEMINI_API_KEY` | Gemini AI in Ask / Report pages |

Set in `.env` before **every** `npm run build` or `npm run cap:sync`. Vite inlines these at build time; they are not read at runtime from `.env` on the device.

## Troubleshooting

- **Blank screen on mobile:** Run `npm run cap:sync` after `npm run build`. Ensure `vite.config.ts` has `base: "./"`.
- **Gemini errors on device:** Rebuild with `VITE_GEMINI_API_KEY` set in `.env` before `npm run build`.
- **iOS pod errors:** `cd ios/App && pod install && cd ../../`
- **Android SDK missing:** Install Android Studio SDK Platform 34+ and accept licenses in SDK Manager.

## What changed vs original dashboard

- `vite.config.ts`: `base: "./"` for Capacitor asset loading
- `capacitor.config.json`, `android/`, `ios/`: native wrappers
- `src/lib/capacitor-init.ts`: hides splash on native only (no web UI change)
- New npm scripts for web and mobile workflows

All pages, charts, authentication flow, styling, and API logic remain unchanged.
